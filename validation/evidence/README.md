# Lab evidence files

This directory is deliberately empty of device captures. Add only sanitised transcripts or screenshots captured from an authorised, isolated Cisco lab. Never add a Cisco image, licence material, credentials, session cookies, production configuration or private addressing that identifies a real environment.

Every evidence file referenced by `validation/lab-evidence.json` must have a matching SHA-256 digest. Passing the validator confirms schema and file integrity; it does not prove that a capture is genuine or promote a command to `verified-on-image`.
